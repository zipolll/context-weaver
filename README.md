# 拾序 · Context Weaver 0.3

不改变现有 AI 使用习惯，用 Chrome 插件整理对话、定位问题和复用上下文。支持 **DeepSeek、ChatGPT、Gemini** 的普通文本对话，数据保存在当前浏览器，无需插件账号或后端。

## 安装与更新

需要 Node.js 22.12+。

```sh
npm ci
npm run build
```

1. 打开 Chrome 的 `chrome://extensions`，启用“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择 **.output/chrome-mv3** 文件夹。
3. 固定插件图标，打开受支持的平台并登录，刷新安装前已打开的网页。
4. 点击插件图标打开知识图侧栏，在右上角“＋”中选择“收纳当前对话到图”。Chrome 的侧栏位置由浏览器设置控制，请设为右侧。

从旧版更新时，在扩展管理页点击现有扩展的刷新按钮，保留同一扩展及本地数据。新增站点权限可能需要在 Chrome 中确认；随后刷新 AI 网页。升级前可在设置中导出备份。

运行 `npm run zip` 生成 **.output/context-weaver-0.3.0-chrome.zip**，解压后按上述步骤加载。扩展尚未上架 Chrome 应用商店。

## 知识图工作区

- **首页是一张知识图**：每张图有自己的名称、唯一所属文件夹（或未分类）和节点位置。重新打开侧栏显示上次操作的图，旧数据自动整理进“我的知识图”。同一对话可复用到多个图。
- **文库目录**：左上角文件夹按钮展开/收起目录树；支持新建、重命名、移动和删除图或文件夹。拖动图到文件夹可归类，删除图不删除原对话。
- **两种节点**：对话节点指向 AI 会话，单击展开或收起问题子图；问题节点对应一轮用户提问，只连接所属对话。双击对话打开原页面，双击问题同时尝试定位。节点可拖动排列并保存位置，不改变问题的真实所属会话。
- **节点详情**：单击节点查看回答摘录、来源与 Tag。只有对话节点提供“新建后续对话”入口。来源继承箭头连接对话节点；引用某个问题时保留轮次来源，其图上父节点仍是所属对话。
- **暂存**：左下角按钮展开清单；节点和网页右键选中的文字均可加入，默认勾选。问题暂存保存该轮问答，对话暂存保存全部已收纳轮次。选择多项后新建对话，成功发送后自动加入原图并连接全部来源对话。暂存保留到手动移除。
- **Tag**：对话与问题分别支持多个 Tag。文库底部可搜索 Tag、按文件夹组织、重命名、移动和合并；点击 Tag 展示包含该 Tag 节点的所有图，不把画布过滤成残缺子图。
- **其他入口**：对话库、旧版片段、草稿在“更多”；设置独立保留。网页右侧文字问题目录继续可用。

### 打开与追问

默认在 **Chrome 原生分栏**中打开节点或新建对话。单页时在右侧创建第二栏，已有两栏时复用右栏，不增加第三栏；可切换成新标签页。若目标已在当前分栏中，直接激活。正在发送的右栏不会被另一打开操作覆盖。

Chrome 155+ 才提供扩展创建原生分栏的接口；更早版本回退到新标签页。分栏使用 chrome.tabs.create 的 splitWithTabId 和已存在的 splitViewId，不使用 iframe 或模拟分栏。API 依据：https://developer.chrome.com/docs/extensions/reference/api/tabs 。浏览器侧栏位置仍由 Chrome 自身控制。

选中文字右键可“加入暂存”“在新对话追问”或“在当前对话追问”。追问面板确认问题、引用和目标后点击“发送”，自动填写并提交；模板和压缩等高级选项继续折叠。新对话的打开方式也可在确认面板选择。

## 自动发送与数据

成功以网页出现对应的用户消息为依据，不等待 AI 回答。双击不会重复提交；点击平台发送按钮后无法确认结果时，显示“请查看原页面确认结果”，不会自动重发。未登录、正在生成或按钮不可用时保留草稿并提示状态。

确认后输入框文字发生变化会停止发送并更新预览，需再次确认。浏览器后台重启、导入备份、重新打开草稿均不自动恢复发送。状态不明的消息请先在原页面核实。

旧版本地数据库和 JSON 备份继续兼容。对话需手动收纳，之后访问原页面时更新已保存的历史；未收纳的普通对话只提供即时目录。其他网站仍可收藏标题、链接或片段。

## 上下文压缩 API

在设置中填写完整的 Chat Completions 接口地址、服务商支持的模型名及 API Key。支持 HTTPS 服务和本机 HTTP 服务（localhost、127.0.0.1），使用时单独请求接口访问权限；三个 AI 网页的必需访问权限限定为对应站点。

只有主动确认压缩或测试连接时才调用服务；压缩前展示目标与引用，可取消，60 秒超时，不自动重试。摘要可编辑、采用或撤销。API Key 保存在扩展可信上下文的本地设置中，不传给网页或内容脚本，也不包含在备份中。接口应返回非流式文本 `choices[0].message.content`。

## 开发与基本验证

```sh
npm run dev          # 开发
npm run typecheck    # 类型检查
npm test             # 单元测试
npm run build        # 生产构建
npm run zip          # 打包
```

0.3 采用基本验证：类型检查、生产构建、现有 20 项核心数据测试，以及一次生产产物的本地界面走查。走查使用真实数据 reducer，覆盖问题展开、双击定位请求、Tag 保存与图筛选、暂存勾选、草稿关联图、切换图后恢复及备份保留新增数据；未建立完整端到端环境。

浏览器原生分栏按 Chrome 155 官方接口实现，并以模拟 Tabs API 检查创建、复用右栏和旧版回退；**未将模拟检查视为真实浏览器分栏验收**。本轮也未重新验证三平台登录后的发送链路。0.2 已完成的平台适配和发送保护继续保留。

## 边界

- 面向 Chrome 桌面端的普通文本对话，不继承附件、图片、语音、工具状态或平台内部思考。
- 平台可能虚拟化或折叠历史；目录不伪造未加载的问题，收纳只读取已渲染文本。先在网页加载更早历史，再重新收纳。
- DOM 选择器集中在各平台适配器中，平台改版可能需要更新。没有稳定消息 ID 时，相同问题的区分依赖可见顺序。
- 跨平台复用传递文本上下文和来源，不迁移平台内部会话状态，也不提供云端账号或同步。
- 来源绑定通过首条用户消息与确认的提示词匹配；平台改写消息或网页连接中断时可能需要在原页面检查。
- 卸载扩展会删除本地数据，请先导出备份。

```text
entrypoints/       后台、内容脚本、侧栏与工作区
src/adapters/     三个平台的 DOM 适配、注册与发送控制
src/core/         数据、来源关系、备份、提示词与压缩 API
src/ui/           对话库、网页问题目录、追问与设置
tests/            核心逻辑、数据库、API 和适配器用例
```
