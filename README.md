# 拾序 · Context Weaver

不改变现有 AI 使用习惯，用 Chrome 插件整理对话、定位问题和复用上下文。EE 黑客松项目，优先适配 DeepSeek。

React + TypeScript + WXT + Manifest V3，无需后端和登录，数据保存在当前浏览器。

## 安装

需要 Node.js 22.12+，推荐 Node.js 24。

~~~sh
npm ci
npm run build
~~~

1. 打开 Chrome 的 chrome://extensions，启用“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择项目中的 **.output/chrome-mv3** 文件夹。
3. 固定扩展图标，打开 DeepSeek 并登录；安装前已打开的页面需要刷新。
4. 点击扩展图标打开侧栏，点击“收纳当前页面”。

运行 npm run zip 可生成扩展 ZIP，解压后按上述步骤加载。未上架 Chrome 应用商店。

## 功能

- **对话管理**：项目、嵌套文件夹、重命名、拖动归类、全文搜索、标签、收藏、归档及原页面跳转。
- **跨 AI 收纳**：DeepSeek 保存已加载的问答文本；其他 AI 网站先保存标题和链接。
- **更新策略**：手动收纳后自动更新，未收纳的对话只提供即时导航。
- **对话导航**：用户提问列表与图切换、点击定位高亮、查看回答、从指定轮次分支。
- **上下文复用**：单个或多个对话继承上下文；默认截至选定轮次，可筛选问答、排序来源、修改引用与提示词。
- **关系图谱**：展示插件记录的分支与汇合，多选节点开启新对话，宽屏工作区可展开查看。
- **选区追问**：选中文字后右键，在当前或新对话追问，快捷解释、举例、检查。
- **片段篮**：收集不同页面的片段，合并多个来源提问。
- **提示词模板**：设置页可编辑追问、解释、举例、检查模板，支持 question、context、sources、action 占位符。
- **上下文压缩**：配置兼容 Chat Completions 的 API，预览提交内容，摘要可编辑、采用和撤销。
- **本地备份**：JSON 导入导出、格式校验、稳定 ID 合并；备份不包含 API Key。

所有操作只填入输入框，**由用户在原网页确认并发送**。已有输入默认保留并追加，替换需要在预览中选择。

## 压缩 API 设置

在设置中填写完整 Chat Completions 接口地址，例如 https://api.deepseek.com/chat/completions，以及服务商当前支持的模型名称和自己的 API Key。

支持 HTTPS 服务与本机 HTTP 服务（localhost、127.0.0.1），Chrome 会请求对应服务的访问权限。接口应返回非流式文本 choices[0].message.content。

只有主动点击“压缩”或“测试连接”时才调用服务。压缩前展示目标服务与引用内容；请求可取消，60 秒超时，不自动重试。API Key 保存在扩展可信上下文的本地设置中，不传给原网页、内容脚本或备份。服务调用费用由服务商收取。

## 开发

~~~sh
npm run dev          # 开发模式
npm run typecheck    # 类型检查
npm test             # 单元测试
npm run build        # 生产构建
npm run check        # 上述基本检查
npm run zip          # 打包扩展
~~~

项目另包含可选 Playwright 扩展测试脚本：先运行 npx playwright install chromium，再运行 npm run test:e2e。它使用独立临时浏览器配置和合成 DeepSeek 页面，不会访问用户 Chrome 数据或真实发送 AI 请求；可设置 PLAYWRIGHT_CHROMIUM_EXECUTABLE 指定测试浏览器。

## 扩展结构

~~~text
entrypoints/       后台、内容脚本、侧栏与工作区入口
src/adapters/     SiteAdapter 能力接口、站点注册和 DeepSeek DOM 适配
src/core/         数据类型、状态变更、IndexedDB Repository、提示词和 API
src/ui/           项目库、导航、关系图、预览与设置
tests/            状态/数据库/API/适配器测试及可选端到端测试
~~~

新增 AI 平台时实现 SiteAdapter，注册适配器并增加内容脚本匹配规则/权限；项目管理和上下文服务可复用。更换保存方式时替换 Repository；数据格式变更应增加版本迁移，保留已有数据和备份兼容性。

## 已知边界与自检

- 类型检查、57 项单元测试与生产构建通过；测试覆盖目录循环、部分历史合并、来源快照、备份、数据库并发、DOM 适配及 API 异常/取消/超时。
- **浏览器端到端测试未完成**：当前 Windows 测试 Chromium 出现程序集加载问题；真实登录后的 DeepSeek 页面尚未人工验收。按首版交付，不将合成页面测试视作真实站点验证。
- DeepSeek 可能虚拟化历史，插件只读取已渲染文本，无法证明完整性。界面会提示不完整；加载更早历史后重新收纳。
- DOM 选择器基于公开页面结构及合成样本，站点改版时可能需要更新适配器。无稳定消息 ID 时，相同问题的区分依赖可见顺序。
- 文本继承不迁移平台内部状态、附件、图片、工具状态或隐藏思考。
- 新对话首条用户消息与插件填写提示词匹配后记录来源；发送前改写提示词可能无法自动绑定关系。
- 填写失败会保留草稿，可复制或重试。浏览器重启后待填写记录恢复为预览。
- 卸载扩展会删除当前浏览器保存的数据，请先导出备份。
